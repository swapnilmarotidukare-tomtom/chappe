# Chappe 0.0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Chappe 0.0.1: one live Slack message per Airflow DAG run, edited in place, with step history in its thread, attached through notifier mode and released internally to one real pipeline.

**Architecture:** Ports and adapters. A pure core (`chappe.core`) holds the domain model, run view, message set, write rules and engine; it imports neither Airflow nor Slack. Adapters implement the ports: the Airflow integration (marker, callbacks, notifier, source), the Slack transport, the Slack message-metadata store, and the `thread` and `plain` themes. Every event rebuilds the whole message set from Airflow's current state; the engine then decides what to send with a watermark (skip and order) and output keys (what is new).

**Tech Stack:** Python ≥3.10, Apache Airflow 3.x (Task SDK), `slack_sdk`, `httpx`, `pydantic` v2, `PyYAML`, `Jinja2` (sandboxed), `uv`, `hatchling`, `pytest`, `hypothesis`, `mypy --strict`, `ruff`, `import-linter`, `pre-commit`, GitHub Actions.

**Spec:** `docs/specs/2026-10-03-chappe-0.0.1-design.md` (revised after the red-team review). Executors read the spec alongside this plan.

## Global Constraints

- Principle, quoted in README: "Chappe never breaks or blocks a pipeline. It prefers being late over being wrong, and silence over a duplicate."
- Nothing raises into Airflow: every callback and engine entry point catches all exceptions and logs them.
- `chappe.core` and `chappe.ports` import neither `airflow`, `slack_sdk` nor `httpx`; enforced by `import-linter` in CI.
- Python `>=3.10`; Airflow `>=3.0.0` (exact minimum minor set from spike findings, Task 1).
- 0.0.1 attaches through **notifier mode only**; no Airflow plugin, no listeners.
- One DAG per process in 0.0.1; the config schema already takes `dags: [...]` and `link:`.
- Store: Slack message metadata. Transport: Slack. Themes: `thread` (default) and `plain` (also the fallback).
- Messages are plain Slack `mrkdwn` text with emoji. No Block Kit, no attachment colors, no charts.
- Slack channel in config is a channel **ID** (`C…` or `G…`), not `#name`.
- Secrets come only from Airflow connections: `chappe_slack` (Slack bot token in `password`) and `chappe_airflow_api` (Airflow API base URL in `host`, credentials in `login`/`password`). Never in YAML, code or logs.
- Theme contract version: `1`. Supported capabilities in 0.0.1: none.
- Distribution is **internal only** until the owner has written permission to open-source: no PyPI upload, no public docs site, no LICENSE file, no public announcement. Task 21 is the gated public release and is not executed without that permission.
- Conventional Commits for every commit (`feat:`, `fix:`, `test:`, `docs:`, `chore:`, `ci:`).
- Typing: `mypy --strict` passes on `src/`.

## Review Focus

1. **Channel given as `#name`** instead of an ID: config validation fails with a message telling the user to use the channel ID (Task 7).
2. **`@milestone` on a mapped task (`.expand()`)**: the DAG still imports and runs; Chappe logs a warning and does not report that task (Task 15).
3. **A configured DAG with no milestones**: no message is posted and nothing errors (Task 16 snapshot returns `None`; Task 14 returns `NO_PROCESS`).
4. **Run ids with special characters** (`manual__2026-10-02T13:35:00+00:00`): Airflow links are URL-encoded and valid (Task 16).
5. **Title template referencing a missing param** (manual trigger without conf): the title falls back to `"<dag_id> · <run_id>"` instead of crashing or printing `None` (Task 16).

```python
# spike/dags/spike_chappe.py  (throwaway)
import json
import os
import socket
import sys
import time

import httpx
from airflow.providers.standard.operators.empty import EmptyOperator
from airflow.sdk import DAG, TaskGroup, task


SINK = os.path.join(os.path.dirname(os.path.abspath(__file__)), "..", "spike_sink.jsonl")


def _progress(tag, step):
    with open(SINK + ".progress", "a") as f:
        f.write(f"{time.time():.1f} pid={os.getpid()} {tag} {step}\n")


def _timed(info, key, fn):
    _progress(info["tag"], "start " + key)
    started = time.monotonic()
    try:
        info[key] = fn()
    except BaseException as exc:  # spike: record everything
        info[key] = "ERROR " + repr(exc)
    info[key + "_ms"] = round((time.monotonic() - started) * 1000)
    _progress(info["tag"], "end " + key)


def report(tag):
    def _callback(context):
        _progress(tag, "enter keys=" + ",".join(sorted(context.keys())))
        dag = context.get("dag")
        dag_run = context.get("dag_run")
        run_id = context.get("run_id") or getattr(dag_run, "run_id", None)
        convert = dag.get_task("prepare.convert") if dag else None
        group = convert.task_group if convert else None
        info = {
            "tag": tag,
            "host": socket.gethostname(),
            "argv": sys.argv[:3],
            "pid": os.getpid(),
            "context_keys": sorted(context.keys()),
            "run_id": run_id,
            "reason": context.get("reason"),
            "ti_type": type(context.get("ti")).__name__,
            "dag_run_type": type(dag_run).__name__,
            "dag_run_state": str(getattr(dag_run, "state", None)),
            "marker": getattr(convert, "chappe_milestone", None),
            "task_display_name": getattr(convert, "task_display_name", None),
            "group_id": getattr(group, "group_id", None),
            "group_display_name": getattr(group, "group_display_name", None),
            "has_on_skipped_callback": hasattr(convert, "on_skipped_callback"),
        }
        for name in ("BaseNotifier", "Connection", "BaseOperator", "TaskGroup"):
            try:
                module = __import__("airflow.sdk", fromlist=[name])
                getattr(module, name)
                info[f"airflow.sdk.{name}"] = True
            except (ImportError, AttributeError) as exc:
                info[f"airflow.sdk.{name}"] = repr(exc)

        # S2f: Task SDK runtime reads, no HTTP and no credentials.
        from airflow.sdk.execution_time.task_runner import RuntimeTaskInstance

        _timed(info, "runtime_task_states", lambda: RuntimeTaskInstance.get_task_states(
            dag_id=dag.dag_id, run_ids=[run_id]))
        if not tag.startswith("dag_"):
            _timed(info, "runtime_dagrun_state", lambda: RuntimeTaskInstance.get_dagrun_state(
                dag_id=dag.dag_id, run_id=run_id))
            _timed(info, "runtime_breadcrumbs", lambda: list(RuntimeTaskInstance.get_task_breadcrumbs(
                dag_id=dag.dag_id, run_id=run_id)))

        # S2g: Connection.get and outbound HTTP in this process.
        conn = None
        try:
            from airflow.sdk import Connection

            conn = Connection.get("chappe_airflow_api")
            info["connection_get"] = {"host": conn.host, "has_password": bool(conn.password)}
        except Exception as exc:
            info["connection_get"] = "ERROR " + repr(exc)
        if conn is not None:
            _timed(info, "outbound_http", lambda: httpx.get(
                f"{conn.host}/api/v2/version", timeout=5).status_code)

            # S2d: REST fallback.
            def _rest():
                token = httpx.post(
                    f"{conn.host}/auth/token",
                    json={"username": conn.login, "password": conn.password},
                    timeout=5,
                ).json()["access_token"]
                response = httpx.get(
                    f"{conn.host}/api/v2/dags/{dag.dag_id}/dagRuns/{run_id}/taskInstances",
                    headers={"Authorization": f"Bearer {token}"},
                    timeout=5,
                )
                body = response.json()
                return {
                    "status": response.status_code,
                    "fields": sorted(body.get("task_instances", [{}])[0].keys()),
                    "states": {t["task_id"]: t["state"] for t in body.get("task_instances", [])},
                }

            _timed(info, "rest", _rest)
        line = json.dumps(info, default=str)
        print("CHAPPE_SPIKE " + line, flush=True)
        with open(SINK, "a") as sink:
            sink.write(line + "\n")
        if tag.startswith("dag_"):  # probed last: not in the DAG processor's message union
            _timed(info, "runtime_dagrun_state", lambda: RuntimeTaskInstance.get_dagrun_state(
                dag_id=dag.dag_id, run_id=run_id))
            _progress(tag, "dagrun_state result " + str(info.get("runtime_dagrun_state")))

    return _callback


with DAG(
    "spike_chappe",
    schedule=None,
    params={"fail": False},
    on_success_callback=report("dag_success"),
    on_failure_callback=report("dag_failure"),
) as dag:
    with TaskGroup("prepare", group_display_name="Prepare data"):
        convert = EmptyOperator(
            task_id="convert",
            task_display_name="Parquet → Delta",
            on_execute_callback=report("task_execute"),
            on_success_callback=report("task_success"),
        )
        convert.chappe_milestone = {"title": "Parquet → Delta"}

    @task(on_failure_callback=report("task_failure"), on_skipped_callback=report("task_skipped"))
    def maybe_fail(params=None):
        if params["fail"]:
            raise RuntimeError("spike failure")

    @task
    def later():
        pass

    convert >> maybe_fail() >> later()
```

```python
# spike/slack_spike.py  (throwaway)
import json
import os
import time

from slack_sdk import WebClient
from slack_sdk.errors import SlackApiError

client = WebClient(token=os.environ["SLACK_BOT_TOKEN"])
channel = os.environ["SLACK_SPIKE_CHANNEL"]
bot_id = client.auth_test()["bot_id"]
print("bot_id", bot_id)

payload = {
    "v": 1,
    "process_key": "spike/run_1",
    "wm_finished": False,
    "wm_last_change": "2026-10-02T08:00:00+00:00",
    "wm_settled": 1,
    "sent_keys": ["step:a:succeeded"],
    "degraded": False,
}
meta = {"event_type": "chappe_process", "event_payload": payload}


def find():
    history = client.conversations_history(channel=channel, limit=50, include_all_metadata=True)
    return [
        m for m in history["messages"]
        if m.get("bot_id") == bot_id and (m.get("metadata") or {}).get("event_type") == "chappe_process"
    ]


parent = client.chat_postMessage(channel=channel, text="spike parent", metadata=meta)["ts"]
print("found after post:", json.dumps(find()[0].get("metadata"), indent=1))

client.chat_update(channel=channel, ts=parent, text="edited without metadata argument")
print("metadata after update without metadata:", find()[0].get("metadata") if find() else None)

payload["sent_keys"].append("step:b:succeeded")
client.chat_update(channel=channel, ts=parent, text="edited with metadata", metadata=meta)
print("metadata after update with metadata:", find()[0].get("metadata"))

client.chat_postMessage(channel=channel, thread_ts=parent, text="broadcast reply", reply_broadcast=True)
duplicate = client.chat_postMessage(channel=channel, text="duplicate parent", metadata=meta)["ts"]
client.chat_delete(channel=channel, ts=duplicate)
print("deleted own duplicate:", duplicate)

started, limited = time.monotonic(), []
for i in range(40):
    try:
        client.chat_update(channel=channel, ts=parent, text=f"burst {i}", metadata=meta)
    except SlackApiError as exc:
        limited.append((i, exc.response["error"], exc.response.headers.get("Retry-After")))
print("burst seconds", round(time.monotonic() - started, 1), "rate limited", limited)

pages, cursor, seen = 0, None, 0
while seen < 400:
    response = client.conversations_history(channel=channel, limit=100, cursor=cursor, include_all_metadata=True)
    pages, seen = pages + 1, seen + len(response["messages"])
    cursor = (response.get("response_metadata") or {}).get("next_cursor")
    if not cursor:
        break
print("history pages", pages, "messages", seen)
```

```python
from __future__ import annotations

from enum import Enum


class ProcessState(str, Enum):
    PENDING = "pending"
    RUNNING = "running"
    SUCCEEDED = "succeeded"
    FAILED = "failed"

    @property
    def finished(self) -> bool:
        return self in (ProcessState.SUCCEEDED, ProcessState.FAILED)


class StepState(str, Enum):
    PENDING = "pending"
    RUNNING = "running"
    SUCCEEDED = "succeeded"
    FAILED = "failed"
    SKIPPED = "skipped"

    @property
    def finished(self) -> bool:
        return self in (StepState.SUCCEEDED, StepState.FAILED, StepState.SKIPPED)


class Capability(str, Enum):
    MULTI_SOURCE = "multi_source"
    ATTEMPTS = "attempts"
```

```python
# src/chappe/core/view.py
"""The read-only run view handed to themes."""

from __future__ import annotations

from dataclasses import dataclass
from datetime import datetime, timedelta, timezone

from chappe.core.model import ProcessState, StepState

_EPOCH = datetime(1970, 1, 1, tzinfo=timezone.utc)


@dataclass(frozen=True, slots=True)
class Link:
    label: str
    url: str


@dataclass(frozen=True, slots=True)
class AttemptView:
    number: int
    state: StepState
    started_at: datetime | None = None
    ended_at: datetime | None = None


@dataclass(frozen=True, slots=True)
class StepView:
    key: str
    title: str
    state: StepState
    started_at: datetime | None = None
    ended_at: datetime | None = None
    error: str | None = None
    links: tuple[Link, ...] = ()
    attempts: tuple[AttemptView, ...] = ()

    def duration(self, now: datetime) -> timedelta | None:
        if self.started_at is None:
            return None
        end = self.ended_at if self.ended_at is not None else now
        return max(end - self.started_at, timedelta(0))


@dataclass(frozen=True, slots=True)
class SectionView:
    key: str
    title: str
    steps: tuple[StepView, ...]

    @property
    def state(self) -> ProcessState:
        states = [s.state for s in self.steps]
        if any(s is StepState.FAILED for s in states):
            return ProcessState.FAILED
        if states and all(s.finished for s in states):
            return ProcessState.SUCCEEDED
        if any(s is not StepState.PENDING for s in states):
            return ProcessState.RUNNING
        return ProcessState.PENDING


@dataclass(frozen=True, slots=True)
class Watermark:
    """How far along a view is. Larger is newer; a finished view beats any unfinished one."""

    finished: bool
    last_change: datetime | None
    settled_steps: int

    def _order(self) -> tuple[bool, datetime, int]:
        return (self.finished, self.last_change or _EPOCH, self.settled_steps)

    def newer_than(self, other: Watermark | None) -> bool:
        return other is None or self._order() > other._order()


@dataclass(frozen=True, slots=True)
class ProcessView:
    key: str
    title: str
    state: ProcessState
    started_at: datetime | None
    ended_at: datetime | None
    now: datetime
    sections: tuple[SectionView, ...]
    links: tuple[Link, ...] = ()

    @property
    def steps(self) -> tuple[StepView, ...]:
        return tuple(step for section in self.sections for step in section.steps)

    @property
    def duration(self) -> timedelta | None:
        if self.started_at is None:
            return None
        end = self.ended_at if self.ended_at is not None else self.now
        return max(end - self.started_at, timedelta(0))

    @property
    def progress(self) -> tuple[int, int]:
        steps = self.steps
        return sum(1 for s in steps if s.state.finished), len(steps)

    @property
    def current_steps(self) -> tuple[StepView, ...]:
        return tuple(s for s in self.steps if s.state is StepState.RUNNING)

    @property
    def failed_steps(self) -> tuple[StepView, ...]:
        return tuple(s for s in self.steps if s.state is StepState.FAILED)

    @property
    def next_steps(self) -> tuple[StepView, ...]:
        found: list[StepView] = []
        for section in self.sections:
            for step in section.steps:
                if step.state is StepState.PENDING:
                    found.append(step)
                    break
        return tuple(found)

    @property
    def watermark(self) -> Watermark:
        times = [t for s in self.steps for t in (s.started_at, s.ended_at) if t is not None]
        times += [t for t in (self.started_at, self.ended_at) if t is not None]
        return Watermark(
            finished=self.state.finished,
            last_change=max(times) if times else None,
            settled_steps=self.progress[0],
        )
```

```python
# src/chappe/core/reconcile.py
"""What has been sent, whether a render may be written, and what to send next."""

from __future__ import annotations

from dataclasses import dataclass

from chappe.core.messages import Alert, MessageSet, ThreadEntry
from chappe.core.view import Watermark


@dataclass(frozen=True, slots=True)
class SentState:
    process_key: str
    parent_ref: str | None = None
    parent_text: str = ""
    watermark: Watermark | None = None
    sent_keys: frozenset[str] = frozenset()
    degraded: bool = False


@dataclass(frozen=True, slots=True)
class SendPlan:
    post_parent: bool
    update_parent: bool
    entries: tuple[ThreadEntry, ...]
    alerts: tuple[Alert, ...]

    @property
    def empty(self) -> bool:
        return not (self.post_parent or self.update_parent or self.entries or self.alerts)


def write_allowed(watermark: Watermark, sent: SentState | None) -> bool:
    """Spec 7.1: never replace newer state, and never replace a finished process with an unfinished one."""
    if sent is None or sent.parent_ref is None:
        return True
    if sent.degraded:
        return False
    if sent.watermark is not None and sent.watermark.finished and not watermark.finished:
        return False
    return watermark.newer_than(sent.watermark)


def plan_sends(messages: MessageSet, sent: SentState | None) -> SendPlan:
    known = sent.sent_keys if sent is not None else frozenset()
    has_parent = sent is not None and sent.parent_ref is not None
    text_changed = sent is not None and messages.parent.text != sent.parent_text
    return SendPlan(
        post_parent=not has_parent,
        update_parent=has_parent and text_changed,
        entries=tuple(e for e in messages.thread if e.key not in known),
        alerts=tuple(a for a in messages.alerts if a.key not in known),
    )
```

```python
"""Everything a theme may use besides the run view."""

from __future__ import annotations

from collections.abc import Mapping
from dataclasses import dataclass, field
from datetime import datetime, timedelta, tzinfo
from typing import Protocol

from chappe.core.model import ProcessState, StepState


class Formatter(Protocol):
    """Supplied by the transport. Every method takes raw text and escapes it."""

    def escape(self, text: str) -> str: ...
    def bold(self, text: str) -> str: ...
    def italic(self, text: str) -> str: ...
    def link(self, url: str, label: str) -> str: ...
    def mention(self, target: str) -> str: ...
    def icon(self, token: str) -> str: ...


@dataclass(frozen=True, slots=True)
class Tokens:
    icons: Mapping[str, str]
    labels: Mapping[str, str]
    extra: Mapping[str, str] = field(default_factory=dict)


@dataclass(frozen=True, slots=True)
class Limits:
    parent_chars: int = 3000
    entry_chars: int = 1500


def format_duration(value: timedelta) -> str:
    seconds = max(int(value.total_seconds()), 0)
    if seconds < 60:
        return f"{seconds}s"
    minutes = seconds // 60
    if minutes < 60:
        return f"{minutes}m"
    hours, minutes = divmod(minutes, 60)
    return f"{hours}h {minutes:02d}m"


def clip(text: str, limit: int) -> str:
    return text if len(text) <= limit else text[: limit - 1] + "…"


@dataclass(frozen=True, slots=True)
class RenderContext:
    tokens: Tokens
    fmt: Formatter
    tz: tzinfo
    alert_mention: str | None = None
    limits: Limits = Limits()

    def icon(self, state: StepState | ProcessState) -> str:
        return self.fmt.icon(self.tokens.icons[state.value])

    def label(self, state: StepState | ProcessState) -> str:
        return self.tokens.labels[state.value]

    def duration(self, value: timedelta | None) -> str:
        return "" if value is None else format_duration(value)

    def clock(self, value: datetime | None) -> str:
        return "" if value is None else value.astimezone(self.tz).strftime("%H:%M")

    def text(self, value: str) -> str:
        return self.fmt.escape(value)
```

```python
# src/chappe/registry.py
"""Finds components registered through Python entry points."""

from __future__ import annotations

from importlib.metadata import entry_points
from typing import Any

from chappe.core.errors import ChappeConfigError

GROUPS = {"theme": "chappe.themes", "store": "chappe.stores", "transport": "chappe.transports"}


def _group(kind: str) -> str:
    if kind not in GROUPS:
        raise ChappeConfigError(f"unknown component kind {kind!r}; expected one of {sorted(GROUPS)}")
    return GROUPS[kind]


def available(kind: str) -> list[str]:
    return sorted(ep.name for ep in entry_points(group=_group(kind)))


def load_component(kind: str, name: str) -> Any:
    for ep in entry_points(group=_group(kind)):
        if ep.name == name:
            return ep.load()
    raise ChappeConfigError(f"unknown {kind} {name!r}; installed: {available(kind)}")
```

```python
from jinja2 import TemplateSyntaxError

    time: TimeConfig = Field(default_factory=TimeConfig)
    budgets: BudgetConfig = Field(default_factory=BudgetConfig)
    airflow_api: AirflowApiConfig = Field(default_factory=AirflowApiConfig)

    dag_id: str
    section: str | None = None

    key: str


class AlertConfig(_Model):
    mention: str | None = None
    on: Literal["final_failure"] = "final_failure"


class SectionOverride(_Model):
    title: str


class MilestoneOverride(_Model):
    title: str | None = None
    section: str | None = None
    hidden: bool = False


class ProcessConfig(_Model):
    enabled: bool = True
    dags: list[DagRef] = Field(min_length=1)
    link: LinkConfig | None = None
    channel: str
    title: str = "{{ dag_id }} · {{ run_id }}"
    theme: ThemeConfig | None = None
    alerts: AlertConfig = Field(default_factory=AlertConfig)
    sections: dict[str, SectionOverride] = Field(default_factory=dict)
    milestones: dict[str, MilestoneOverride] = Field(default_factory=dict)

    @field_validator("dags")
    @classmethod
    def _one_dag(cls, value: list[DagRef]) -> list[DagRef]:
        if len(value) > 1:
            raise ValueError("a process lists exactly one DAG in 0.0.1; multi-DAG processes arrive in Chappe 0.0.3")
        return value

    @field_validator("channel")
    @classmethod
    def _channel_id(cls, value: str) -> str:
        if not CHANNEL_ID.match(value):
            raise ValueError(f"use the Slack channel ID (for example C0123456789), not {value!r}")
        return value

    @field_validator("title")
    @classmethod
    def _title_template(cls, value: str) -> str:
        try:
            _TEMPLATES.parse(value)
        except TemplateSyntaxError as exc:
            raise ValueError(f"title template does not parse: {exc.message}") from exc
        return value


class ChappeSettings(_Model):
    enabled: bool = True
    defaults: Defaults = Field(default_factory=Defaults)
    processes: dict[str, ProcessConfig] = Field(default_factory=dict)

    @model_validator(mode="after")
    def _dag_in_one_process(self) -> ChappeSettings:
        owner: dict[str, str] = {}
        for name, process in self.processes.items():
            for ref in process.dags:
                if ref.dag_id in owner:
                    raise ValueError(f"DAG {ref.dag_id!r} is listed in processes {owner[ref.dag_id]!r} and {name!r}")
                owner[ref.dag_id] = name
        return self

    def process_for_dag(self, dag_id: str) -> tuple[str, ProcessConfig] | None:
        for name, process in self.processes.items():
            if any(ref.dag_id == dag_id for ref in process.dags):
                return name, process
        return None

    def theme_for(self, process: ProcessConfig) -> ThemeConfig:
        return process.theme or self.defaults.theme


class ConfigFile(_Model):
    chappe: ChappeSettings
```

```python
# src/chappe/config/loader.py
from __future__ import annotations

import os
from pathlib import Path

import yaml
from pydantic import ValidationError

from chappe.config.models import ChappeSettings, ConfigFile
from chappe.core.errors import ChappeConfigError

ENV_CONFIG = "CHAPPE_CONFIG"
ENV_ENABLED = "CHAPPE_ENABLED"


def load_settings(path: str | Path | None = None) -> ChappeSettings:
    location = path or os.environ.get(ENV_CONFIG)
    if not location:
        raise ChappeConfigError(f"no config file: pass a path or set {ENV_CONFIG}")
    file = Path(location)
    try:
        data = yaml.safe_load(file.read_text())
    except OSError as exc:
        raise ChappeConfigError(f"{file}: cannot read ({exc.strerror})") from exc
    except yaml.YAMLError as exc:
        raise ChappeConfigError(f"{file}: invalid YAML ({exc})") from exc
    try:
        return ConfigFile.model_validate(data).chappe
    except ValidationError as exc:
        problems = "; ".join(
            f"{'.'.join(str(p) for p in err['loc'])}: {err['msg']}" for err in exc.errors()
        )
        raise ChappeConfigError(f"{file}: {problems}") from exc


def chappe_enabled(settings: ChappeSettings) -> bool:
    if os.environ.get(ENV_ENABLED, "").strip().lower() in {"0", "false", "no", "off"}:
        return False
    return settings.enabled
```

```python
# src/chappe/themes/tokens.py
from __future__ import annotations

from collections.abc import Mapping
from importlib.resources import files
from typing import Any

import yaml

from chappe.core.errors import ChappeConfigError
from chappe.core.render import Tokens

STATE_KEYS = frozenset({"pending", "running", "succeeded", "failed", "skipped"})
_SECTIONS = ("icons", "labels", "extra")


def _builtin(theme_name: str) -> dict[str, Any]:
    resource = files("chappe.themes.builtin").joinpath(f"{theme_name}.yaml")
    if not resource.is_file():
        raise ChappeConfigError(f"theme {theme_name!r} has no built-in tokens; set tokens.extends")
    data = yaml.safe_load(resource.read_text())
    return {section: dict(data.get(section, {})) for section in _SECTIONS}


def resolve_tokens(theme_name: str, override: Mapping[str, Any] | None) -> Tokens:
    override = dict(override or {})
    base_name = str(override.pop("extends", theme_name))
    unknown = set(override) - set(_SECTIONS)
    if unknown:
        raise ChappeConfigError(f"unknown token section(s) {sorted(unknown)}; expected {list(_SECTIONS)}")
    data = _builtin(base_name)
    for section in ("icons", "labels"):
        for key in override.get(section, {}):
            if key not in STATE_KEYS:
                raise ChappeConfigError(f"unknown token {section}.{key}; expected one of {sorted(STATE_KEYS)}")
    for section in _SECTIONS:
        data[section].update({str(k): str(v) for k, v in override.get(section, {}).items()})
    for section in ("icons", "labels"):
        missing = STATE_KEYS - set(data[section])
        if missing:
            raise ChappeConfigError(f"tokens.{section} is missing {sorted(missing)}")
    return Tokens(icons=data["icons"], labels=data["labels"], extra=data["extra"])
```

```python
class SlackFormatter:
    """Slack mrkdwn. Every method escapes the text it is given."""

    def escape(self, text: str) -> str:
        return text.replace("&", "&amp;").replace("<", "&lt;").replace(">", "&gt;")

    def bold(self, text: str) -> str:
        return f"*{self.escape(text)}*"

    def italic(self, text: str) -> str:
        return f"_{self.escape(text)}_"

    def link(self, url: str, label: str) -> str:
        safe_url = url.replace("|", "%7C").replace(">", "%3E")
        return f"<{safe_url}|{self.escape(label)}>"

    def mention(self, target: str) -> str:
        return target  # comes from trusted config, already in Slack syntax

    def icon(self, token: str) -> str:
        return token
```

```python
from chappe.core.view import Link, ProcessView, SectionView, StepView

BASE = datetime(2026, 10, 2, 8, 5, tzinfo=timezone.utc)


def _slug(text: str) -> str:
    return re.sub(r"[^a-z0-9]+", "_", text.lower()).strip("_") or "step"


class ProcessViewBuilder:
    def __init__(self, title: str = "orders 2026.10.1", key: str = "sample/run_1") -> None:
        self._title = title
        self._key = key
        self._sections: list[tuple[str, str, list[StepView]]] = []
        self._cursor = BASE
        self._state: ProcessState | None = None

    def section(self, title: str, key: str | None = None) -> ProcessViewBuilder:
        self._sections.append((key or _slug(title), title, []))
        return self

    def step(
        self, title: str, state: StepState, minutes: int = 30, error: str | None = None
    ) -> ProcessViewBuilder:
        if not self._sections:
            raise ValueError("call section() before step()")
        section_key, _, steps = self._sections[-1]
        started = ended = None
        if state is StepState.RUNNING:
            started = self._cursor
        elif state.finished:
            started = self._cursor
            ended = self._cursor + timedelta(minutes=minutes)
            self._cursor = ended
        steps.append(
            StepView(
                key=f"{section_key}.{_slug(title)}.{len(steps)}",
                title=title,
                state=state,
                started_at=started,
                ended_at=ended,
                error=error,
                links=(Link("Log", f"https://airflow.example/log/{section_key}/{len(steps)}"),),
            )
        )
        return self

    def finished(self, state: ProcessState) -> ProcessViewBuilder:
        self._state = state
        return self

    def build(self, now: datetime | None = None) -> ProcessView:
        sections = tuple(SectionView(key, title, tuple(steps)) for key, title, steps in self._sections)
        all_steps = [s for section in sections for s in section.steps]
        state = self._state or (
            ProcessState.RUNNING
            if any(s.state is not StepState.PENDING for s in all_steps)
            else ProcessState.PENDING
        )
        moment = now or self._cursor + timedelta(minutes=5)
        starts = [s.started_at for s in all_steps if s.started_at is not None]
        return ProcessView(
            key=self._key,
            title=self._title,
            state=state,
            started_at=min(starts) if starts else None,
            ended_at=moment if state.finished else None,
            now=moment,
            sections=sections,
            links=(Link("Airflow run", "https://airflow.example/dags/orders/runs/run_1"),),
        )
```

```python
"""Theme conformance suite. Subclass it in your tests and set `theme` (and `tokens` if needed)."""

from __future__ import annotations

import dataclasses
from collections.abc import Mapping
from datetime import timedelta
from typing import Any, ClassVar

import pytest

from chappe.core.messages import MessageSet
from chappe.core.render import RenderContext
from chappe.ports.theme import SUPPORTED_CAPABILITIES, THEME_CONTRACT_VERSION
from chappe.testing.samples import FAILED_SAMPLES, SAMPLES, SINGLE_SECTION_SAMPLES

ALL_SAMPLES = sorted(SAMPLES)


class ThemeConformance:
    theme: ClassVar[type[Any]]
    tokens: ClassVar[Mapping[str, Any] | None] = None

    def context(self) -> RenderContext:
        from chappe.testing import default_context

        base = (self.tokens or {}).get("extends", self.theme.name)
        return default_context(str(base), self.tokens)

    def render(self, sample: str, *, later: timedelta = timedelta(0)) -> MessageSet:
        view = SAMPLES[sample]
        if later:
            view = dataclasses.replace(view, now=view.now + later)
        result = self.theme().render(view, self.context())
        assert isinstance(result, MessageSet), "render() must return a MessageSet"
        return result

    def test_contract_version_is_supported(self) -> None:
        assert 1 <= self.theme.contract_version <= THEME_CONTRACT_VERSION

    def test_declares_only_supported_capabilities(self) -> None:
        assert frozenset(self.theme.capabilities) <= SUPPORTED_CAPABILITIES

    @pytest.mark.parametrize("sample", ALL_SAMPLES)
    def test_render_is_deterministic(self, sample: str) -> None:
        assert self.render(sample) == self.render(sample)

    @pytest.mark.parametrize("sample", ALL_SAMPLES)
    def test_process_state_is_stated_in_words(self, sample: str) -> None:
        label = self.context().label(SAMPLES[sample].state)
        assert label in self.render(sample).parent.text

    @pytest.mark.parametrize("sample", ALL_SAMPLES)
    def test_messages_stay_within_limits(self, sample: str) -> None:
        limits = self.context().limits
        messages = self.render(sample)
        assert messages.parent.fallback_text.strip()
        assert len(messages.parent.text) <= limits.parent_chars
        for item in (*messages.thread, *messages.alerts):
            assert len(item.text) <= limits.entry_chars

        assert len(keys) == len(set(keys))

        def keys(messages: MessageSet) -> set[str]:
```

```python
"""Minimal theme; also the fallback when another theme fails."""

from __future__ import annotations

from typing import ClassVar

from chappe.core.messages import Alert, MessageSet, ParentMessage, ThreadEntry
from chappe.core.model import Capability, ProcessState
from chappe.core.render import RenderContext, clip
from chappe.core.view import ProcessView


class PlainTheme:
    name: ClassVar[str] = "plain"
    contract_version: ClassVar[int] = 1
    capabilities: ClassVar[frozenset[Capability]] = frozenset()

    def render(self, view: ProcessView, ctx: RenderContext) -> MessageSet:
        done, total = view.progress
        status = f"{ctx.icon(view.state)} {ctx.label(view.state)}"
        steps_word = ctx.tokens.extra.get("steps", "steps")
        parent = f"{ctx.fmt.bold(view.title)} · {status} · {done}/{total} {steps_word}"
        if view.links:
            parent += " · " + " · ".join(ctx.fmt.link(link.url, link.label) for link in view.links)
        fallback = f"{view.title}: {ctx.label(view.state)} ({done}/{total})"

        thread: tuple[ThreadEntry, ...] = ()
        if view.state.finished:
            text = f"{status} · {ctx.fmt.bold(view.title)}"
            if view.duration is not None:
                text += f" · {ctx.duration(view.duration)}"
```

```python
# src/chappe/themes/builtin/thread.py
"""Default theme: status header, one icon row per section, history in the thread."""

from __future__ import annotations

from typing import ClassVar

from chappe.core.messages import Alert, MessageSet, ParentMessage, ThreadEntry
from chappe.core.model import Capability, ProcessState, StepState
from chappe.core.render import RenderContext, clip
from chappe.core.view import ProcessView, SectionView, StepView


class ThreadTheme:
    name: ClassVar[str] = "thread"
    contract_version: ClassVar[int] = 1
    capabilities: ClassVar[frozenset[Capability]] = frozenset()

    def render(self, view: ProcessView, ctx: RenderContext) -> MessageSet:
        done, total = view.progress
        fallback = f"{view.title}: {ctx.label(view.state)} ({done}/{total})"
        parent = clip(self._parent(view, ctx), ctx.limits.parent_chars)
        return MessageSet(ParentMessage(parent, fallback), self._thread(view, ctx), self._alerts(view, ctx))

    def _parent(self, view: ProcessView, ctx: RenderContext) -> str:
        head = f"{ctx.icon(view.state)} {ctx.fmt.bold(view.title)} · {ctx.label(view.state)}"
        if view.duration is not None:
            head += f" · {ctx.duration(view.duration)}"
        lines = [head]
        multi = len(view.sections) > 1
        for section in view.sections:
            icons = "".join(ctx.icon(step.state) for step in section.steps)
            if multi:
                lines.append(f"{icons}  {ctx.fmt.bold(section.title)} · {self._detail(section, ctx)}")
            else:
                finished = sum(1 for step in section.steps if step.state.finished)
                lines.append(f"{icons}  {finished}/{len(section.steps)} {ctx.tokens.extra.get('steps', 'steps')}")
        if view.current_steps:
            running = ", ".join(
                f"{ctx.text(step.title)} ({ctx.duration(step.duration(view.now))})" for step in view.current_steps
            )
            lines.append(f"{ctx.tokens.extra.get('now', 'Now')}: {running}")
        if view.links:
            lines.append(" · ".join(ctx.fmt.link(link.url, link.label) for link in view.links))
        return "\n".join(lines)

    def _detail(self, section: SectionView, ctx: RenderContext) -> str:
        failed = [s for s in section.steps if s.state is StepState.FAILED]
        if failed:
            return f"{ctx.label(StepState.FAILED)}: {ctx.text(failed[0].title)}"
        running = [s for s in section.steps if s.state is StepState.RUNNING]
        if running:
            return ctx.text(running[0].title)
        return ctx.label(section.state)

    def _thread(self, view: ProcessView, ctx: RenderContext) -> tuple[ThreadEntry, ...]:
        multi = len(view.sections) > 1
        finished: list[tuple[SectionView, StepView]] = [
            (section, step) for section in view.sections for step in section.steps if step.state.finished
        ]
        finished.sort(key=lambda pair: pair[1].ended_at or view.now)
        entries: list[ThreadEntry] = []
        for section, step in finished:
            where = f" ({ctx.text(section.title)})" if multi else ""
            text = f"{ctx.icon(step.state)} {ctx.fmt.bold(step.title)}{where} · {ctx.label(step.state)}"
            duration = step.duration(view.now)
            if step.state is not StepState.SKIPPED and duration is not None:
                text += f" · {ctx.duration(duration)}"
            if step.links:
                text += " · " + " · ".join(ctx.fmt.link(link.url, link.label) for link in step.links)
            if step.error:
                text += f"\n{ctx.text(step.error)}"
            entries.append(ThreadEntry(key=f"step:{step.key}:{step.state.value}", text=clip(text, ctx.limits.entry_chars)))
        if view.state.finished:
            text = f"{ctx.icon(view.state)} {ctx.fmt.bold(view.title)} · {ctx.label(view.state)}"
            if view.duration is not None:
                text += f" · {ctx.duration(view.duration)}"
            if view.links:
                text += " · " + " · ".join(ctx.fmt.link(link.url, link.label) for link in view.links)
            entries.append(ThreadEntry(key=f"process:{view.state.value}", text=text, broadcast=True))
        return tuple(entries)

    def _alerts(self, view: ProcessView, ctx: RenderContext) -> tuple[Alert, ...]:
        if view.state is not ProcessState.FAILED:
            return ()
        mention = f"{ctx.fmt.mention(ctx.alert_mention)} " if ctx.alert_mention else ""
        failed = view.failed_steps
        details = (
            "; ".join(ctx.text(s.title) + (f": {ctx.text(s.error)}" if s.error else "") for s in failed)
            if failed
            else ctx.label(ProcessState.FAILED)
        )
        text = f"{mention}{ctx.icon(ProcessState.FAILED)} {ctx.fmt.bold(view.title)} · {details}"
        logs = [link for step in failed for link in step.links]
        if logs:
            text += " · " + " · ".join(ctx.fmt.link(link.url, link.label) for link in logs)
        return (Alert(key="alert:process:failed", text=clip(text, ctx.limits.entry_chars)),)
```

```python
# src/chappe/transports/slack/api.py
"""Thin, typed wrapper over the Slack Web API with error classification and retries."""

from __future__ import annotations

import time
from collections.abc import Callable, Mapping
from dataclasses import dataclass
from typing import Any, Protocol, TypeVar

from chappe.core.errors import TransportError

T = TypeVar("T")
RETRYABLE = frozenset(
    {"ratelimited", "rate_limited", "internal_error", "fatal_error", "service_unavailable", "request_timeout"}
)


@dataclass(frozen=True, slots=True)
class SlackMessage:
    ts: str
    text: str
    bot_id: str | None
    metadata: Mapping[str, Any] | None
    thread_ts: str | None = None


class SlackApi(Protocol):
    def post(
        self,
        channel: str,
        text: str,
        *,
        thread_ts: str | None = None,
        broadcast: bool = False,
        metadata: Mapping[str, Any] | None = None,
    ) -> str: ...

    def update(self, channel: str, ts: str, text: str, *, metadata: Mapping[str, Any] | None = None) -> None: ...

    def delete(self, channel: str, ts: str) -> None: ...

    def history(self, channel: str, *, limit: int, cursor: str | None = None) -> tuple[list[SlackMessage], str | None]: ...

    def bot_id(self) -> str: ...


def call_with_retry(
    fn: Callable[[], T],
    *,
    deadline: float,
    clock: Callable[[], float] = time.monotonic,
    sleep: Callable[[float], None] = time.sleep,
) -> T:
    attempt = 0
    while True:
        try:
            return fn()
        except TransportError as exc:
            if not exc.retryable:
                raise
            wait = exc.retry_after if exc.retry_after is not None else min(0.5 * 2**attempt, 8.0)
            if clock() + wait > deadline:
                raise
            sleep(wait)
            attempt += 1


class WebClientSlackApi:
    """Real Slack client. Requires the scopes chat:write and channels:history (groups:history for private channels)."""

    def __init__(self, token: str, *, timeout: float = 5.0) -> None:
        from slack_sdk import WebClient

        self._client = WebClient(token=token, timeout=int(timeout))
        self._bot_id: str | None = None

    def _call(self, method: str, **kwargs: Any) -> Any:
        from slack_sdk.errors import SlackApiError

        try:
            return getattr(self._client, method)(**kwargs)
        except SlackApiError as exc:
            code = str(exc.response.get("error", "unknown_error"))
            retry_after = exc.response.headers.get("Retry-After")
            retryable = code in RETRYABLE or exc.response.status_code >= 500
            raise TransportError(code, retryable=retryable, retry_after=float(retry_after) if retry_after else None) from exc
        except (TimeoutError, OSError) as exc:
            raise TransportError("network_error", retryable=True) from exc

    def post(
        self,
        channel: str,
        text: str,
        *,
        thread_ts: str | None = None,
        broadcast: bool = False,
        metadata: Mapping[str, Any] | None = None,
    ) -> str:
        kwargs: dict[str, Any] = {"channel": channel, "text": text}
        if thread_ts:
            kwargs.update(thread_ts=thread_ts, reply_broadcast=broadcast)
        if metadata is not None:
            kwargs["metadata"] = dict(metadata)
        return str(self._call("chat_postMessage", **kwargs)["ts"])

    def update(self, channel: str, ts: str, text: str, *, metadata: Mapping[str, Any] | None = None) -> None:
        kwargs: dict[str, Any] = {"channel": channel, "ts": ts, "text": text}
        if metadata is not None:
            kwargs["metadata"] = dict(metadata)
        self._call("chat_update", **kwargs)

    def delete(self, channel: str, ts: str) -> None:
        self._call("chat_delete", channel=channel, ts=ts)

    def history(self, channel: str, *, limit: int, cursor: str | None = None) -> tuple[list[SlackMessage], str | None]:
        response = self._call(
            "conversations_history", channel=channel, limit=limit, cursor=cursor, include_all_metadata=True
        )
        messages = [
            SlackMessage(
                ts=str(m["ts"]),
                text=str(m.get("text", "")),
                bot_id=m.get("bot_id"),
                metadata=m.get("metadata"),
                thread_ts=m.get("thread_ts"),
            )
            for m in response.get("messages", [])
        ]
        next_cursor = (response.get("response_metadata") or {}).get("next_cursor") or None
        return messages, next_cursor

    def bot_id(self) -> str:
        if self._bot_id is None:
            self._bot_id = str(self._call("auth_test")["bot_id"])
        return self._bot_id
```

```python
from __future__ import annotations

import time
from collections.abc import Callable

from chappe.transports.slack.api import SlackApi, call_with_retry
from chappe.transports.slack.formatter import SlackFormatter


class SlackTransport:
    def __init__(
        self,
        api: SlackApi,
        *,
        clock: Callable[[], float] = time.monotonic,
        sleep: Callable[[float], None] = time.sleep,
    ) -> None:
        self._api = api
        self._clock = clock
        self._sleep = sleep
        self._formatter = SlackFormatter()

    @property
    def formatter(self) -> SlackFormatter:
        return self._formatter

    def post_parent(self, channel: str, text: str, fallback: str, *, deadline: float) -> str:
        return call_with_retry(lambda: self._api.post(channel, text), deadline=deadline, clock=self._clock, sleep=self._sleep)

    def update_parent(self, channel: str, ref: str, text: str, fallback: str, *, deadline: float) -> None:
        call_with_retry(lambda: self._api.update(channel, ref, text), deadline=deadline, clock=self._clock, sleep=self._sleep)

    def post_reply(self, channel: str, parent_ref: str, text: str, *, broadcast: bool, deadline: float) -> str:
        return call_with_retry(
            lambda: self._api.post(channel, text, thread_ts=parent_ref, broadcast=broadcast),
            deadline=deadline,
            clock=self._clock,
            sleep=self._sleep,
        )

    def delete(self, channel: str, ref: str, *, deadline: float) -> None:
        call_with_retry(lambda: self._api.delete(channel, ref), deadline=deadline, clock=self._clock, sleep=self._sleep)
```

```python
# src/chappe/testing/fakes.py
"""In-memory Slack for tests. Behaves like the parts of the Web API Chappe uses."""

from __future__ import annotations

from collections.abc import Mapping
from typing import Any

from chappe.core.errors import TransportError
from chappe.transports.slack.api import SlackMessage


class FakeSlackApi:
    def __init__(self, bot: str = "B0CHAPPE") -> None:
        self._bot = bot
        self._seq = 0
        self._channels: dict[str, dict[str, SlackMessage]] = {}
        self._failures: list[TransportError] = []
        self.calls: list[tuple[str, dict[str, Any]]] = []

    def fail_next(self, error: TransportError) -> None:
        self._failures.append(error)

    def _maybe_fail(self) -> None:
        if self._failures:
            raise self._failures.pop(0)

    def _next_ts(self) -> str:
        self._seq += 1
        return f"1790000000.{self._seq:06d}"

    def insert(
        self, channel: str, ts: str, text: str, metadata: Mapping[str, Any] | None = None, bot_id: str | None = None
    ) -> None:
        self._channels.setdefault(channel, {})[ts] = SlackMessage(ts, text, bot_id or self._bot, metadata)

    def post(
        self,
        channel: str,
        text: str,
        *,
        thread_ts: str | None = None,
        broadcast: bool = False,
        metadata: Mapping[str, Any] | None = None,
    ) -> str:
        self.calls.append(("post", {"channel": channel, "text": text, "thread_ts": thread_ts, "broadcast": broadcast}))
        self._maybe_fail()
        ts = self._next_ts()
        self._channels.setdefault(channel, {})[ts] = SlackMessage(ts, text, self._bot, metadata, thread_ts)
        return ts

    def update(self, channel: str, ts: str, text: str, *, metadata: Mapping[str, Any] | None = None) -> None:
        self.calls.append(("update", {"channel": channel, "ts": ts, "text": text}))
        self._maybe_fail()
        old = self._channels[channel][ts]
        self._channels[channel][ts] = SlackMessage(ts, text, old.bot_id, metadata if metadata is not None else old.metadata, old.thread_ts)

    def delete(self, channel: str, ts: str) -> None:
        self.calls.append(("delete", {"channel": channel, "ts": ts}))
        self._maybe_fail()
        self._channels.get(channel, {}).pop(ts, None)

    def history(self, channel: str, *, limit: int, cursor: str | None = None) -> tuple[list[SlackMessage], str | None]:
        self.calls.append(("history", {"channel": channel, "limit": limit, "cursor": cursor}))
        self._maybe_fail()
        newest_first = sorted(self.top_level(channel), key=lambda m: float(m.ts), reverse=True)
        start = int(cursor or 0)
        page = newest_first[start : start + limit]
        more = start + limit < len(newest_first)
        return page, str(start + limit) if more else None

    def bot_id(self) -> str:
        return self._bot

    def top_level(self, channel: str) -> list[SlackMessage]:
        messages = self._channels.get(channel, {}).values()
        return sorted((m for m in messages if m.thread_ts is None), key=lambda m: float(m.ts))

    def replies(self, channel: str, parent_ts: str) -> list[SlackMessage]:
        messages = self._channels.get(channel, {}).values()
        return sorted((m for m in messages if m.thread_ts == parent_ts), key=lambda m: float(m.ts))
```

```python
# src/chappe/stores/slack_metadata.py
"""Delivery state stored as hidden metadata on the parent Slack message (spec 8.2)."""

from __future__ import annotations

import time
from collections.abc import Callable, Mapping
from datetime import datetime
from typing import Any, ClassVar

from chappe.core.errors import StoreError
from chappe.core.reconcile import SentState
from chappe.core.view import Watermark
from chappe.transports.slack.api import SlackApi, SlackMessage, call_with_retry

EVENT_TYPE = "chappe_process"
PAYLOAD_VERSION = 1


def _encode(state: SentState) -> dict[str, Any]:
    wm = state.watermark
    return {
        "event_type": EVENT_TYPE,
        "event_payload": {
            "v": PAYLOAD_VERSION,
            "process_key": state.process_key,
            "wm_finished": bool(wm and wm.finished),
            "wm_last_change": wm.last_change.isoformat() if wm and wm.last_change else "",
            "wm_settled": wm.settled_steps if wm else 0,
            "has_wm": wm is not None,
            "sent_keys": sorted(state.sent_keys),
            "degraded": state.degraded,
        },
    }


def _decode(message: SlackMessage) -> SentState:
    payload: Mapping[str, Any] = (message.metadata or {}).get("event_payload", {})
    watermark = None
    if payload.get("has_wm", True):
        last = str(payload.get("wm_last_change", ""))
        watermark = Watermark(
            finished=bool(payload.get("wm_finished", False)),
            last_change=datetime.fromisoformat(last) if last else None,
            settled_steps=int(payload.get("wm_settled", 0)),
        )
    return SentState(
        process_key=str(payload["process_key"]),
        parent_ref=message.ts,
        parent_text=message.text,
        watermark=watermark,
        sent_keys=frozenset(str(k) for k in payload.get("sent_keys", [])),
        degraded=bool(payload.get("degraded", False)),
    )


class SlackMetadataStore:
    writes_parent: ClassVar[bool] = True

    def __init__(
        self,
        api: SlackApi,
        channel: str,
        *,
        scan_depth: int = 200,
        clock: Callable[[], float] = time.monotonic,
        sleep: Callable[[float], None] = time.sleep,
    ) -> None:
        self._api = api
        self._channel = channel
        self._depth = scan_depth
        self._clock = clock
        self._sleep = sleep

    def _retry(self, fn: Callable[[], Any], deadline: float) -> Any:
        return call_with_retry(fn, deadline=deadline, clock=self._clock, sleep=self._sleep)

    def _scan(self, process_key: str, deadline: float) -> list[SlackMessage]:
        bot = self._retry(self._api.bot_id, deadline)
        found: list[SlackMessage] = []
        seen, cursor = 0, None
        while seen < self._depth:
            limit = min(100, self._depth - seen)
            page, cursor = self._retry(
                lambda c=cursor, n=limit: self._api.history(self._channel, limit=n, cursor=c), deadline
            )
            seen += len(page)
            for message in page:
                meta = message.metadata or {}
                payload = meta.get("event_payload") or {}
                if message.bot_id == bot and meta.get("event_type") == EVENT_TYPE and payload.get("process_key") == process_key:
                    found.append(message)
            if not cursor or not page:
                break
        return sorted(found, key=lambda m: float(m.ts))

    def find_parents(self, process_key: str, *, deadline: float) -> list[str]:
        return [m.ts for m in self._scan(process_key, deadline)]

    def load(self, process_key: str, *, deadline: float) -> SentState | None:
        found = self._scan(process_key, deadline)
        return _decode(found[0]) if found else None

    def save(self, state: SentState, *, deadline: float) -> None:
        if state.parent_ref is None:
            raise StoreError("cannot save delivery state before the parent message exists")
        ref = state.parent_ref
        self._retry(lambda: self._api.update(self._channel, ref, state.parent_text, metadata=_encode(state)), deadline)
```

```python
# src/chappe/core/engine.py
"""Event → snapshot → load → write rules → render → plan → send and save (spec 7)."""

from __future__ import annotations

import logging
import time
from collections.abc import Callable
from dataclasses import dataclass, replace
from enum import Enum

from chappe.core.errors import TransportError
from chappe.core.events import ChappeEvent, EventKind
from chappe.core.messages import MessageSet
from chappe.core.reconcile import SentState, plan_sends, write_allowed
from chappe.core.render import RenderContext
from chappe.core.view import ProcessView
from chappe.ports.source import Source
from chappe.ports.store import Store
from chappe.ports.theme import Theme
from chappe.ports.transport import Transport

log = logging.getLogger("chappe")


class HandleResult(str, Enum):
    DISABLED = "disabled"
    NO_PROCESS = "no_process"
    SKIPPED = "skipped"
    DEGRADED = "degraded"
    YIELDED = "yielded"
    SENT = "sent"
    ERROR = "error"


@dataclass(frozen=True, slots=True)
class EngineSettings:
    channel: str
    event_budget_s: float = 10.0
    final_budget_s: float = 30.0
    final_check_delay_s: float = 2.0


class Engine:
    def __init__(
        self,
        *,
        source: Source,
        theme: Theme,
        fallback_theme: Theme,
        context: RenderContext,
        transport: Transport,
        store: Store,
        settings: EngineSettings,
        enabled: Callable[[], bool] = lambda: True,
        metrics: Callable[[str], None] = lambda name: None,
        clock: Callable[[], float] = time.monotonic,
        sleep: Callable[[float], None] = time.sleep,
    ) -> None:
        self._source = source
        self._theme = theme
        self._fallback = fallback_theme
        self._ctx = context
        self._transport = transport
        self._store = store
        self._settings = settings
        self._enabled = enabled
        self._metrics = metrics
        self._clock = clock
        self._sleep = sleep

    def handle(self, event: ChappeEvent) -> HandleResult:
        """Never raises: Chappe must not break the pipeline."""
        try:
            if not self._enabled():
                return HandleResult.DISABLED
            final = event.kind is EventKind.RUN_FINISHED
            budget = self._settings.final_budget_s if final else self._settings.event_budget_s
            result = self._handle(event, final, self._clock() + budget)
        except Exception:
            log.exception("chappe: event failed", extra={"chappe_process": event.process, "chappe_run": event.run_id})
            result = HandleResult.ERROR
        self._metrics(f"chappe.events.{result.value}")
        return result

    def _handle(self, event: ChappeEvent, final: bool, deadline: float) -> HandleResult:
        view = self._source.snapshot(event)
        if view is None:
            return HandleResult.NO_PROCESS
        sent = self._store.load(view.key, deadline=deadline)
        if sent is not None and sent.degraded:
            return HandleResult.DEGRADED
        if not write_allowed(view.watermark, sent):
            return HandleResult.SKIPPED
        messages = self._render(view)
        try:
            result = self._apply(view, messages, sent, deadline)
        except TransportError as exc:
            if exc.retryable:
                raise
            self._mark_degraded(view, sent, exc, deadline)
            return HandleResult.DEGRADED
        if result is HandleResult.SENT and final:
            self._final_check(view, messages, deadline)
        return result

    def _render(self, view: ProcessView) -> MessageSet:
        try:
            return self._theme.render(view, self._ctx)
        except Exception:
            log.exception("chappe: theme %r failed; using the plain theme", self._theme.name)
            self._metrics("chappe.theme_fallback")
            return self._fallback.render(view, self._ctx)

    def _write_parent(self, state: SentState, deadline: float) -> None:
        if not self._store.writes_parent and state.parent_ref is not None:
            self._transport.update_parent(
                self._settings.channel, state.parent_ref, state.parent_text, state.parent_text, deadline=deadline
            )
        self._store.save(state, deadline=deadline)

    def _apply(self, view: ProcessView, messages: MessageSet, sent: SentState | None, deadline: float) -> HandleResult:
        channel = self._settings.channel
        state = sent if sent is not None else SentState(process_key=view.key)

        if state.parent_ref is None:
            ref = self._transport.post_parent(channel, messages.parent.text, messages.parent.fallback_text, deadline=deadline)
            state = replace(state, parent_ref=ref, parent_text=messages.parent.text, watermark=view.watermark)
            self._store.save(state, deadline=deadline)
            parents = self._store.find_parents(view.key, deadline=deadline)
            if parents and parents[0] != ref:
                self._transport.delete(channel, ref, deadline=deadline)
                self._metrics("chappe.duplicate_parent_healed")
                winner = self._store.load(view.key, deadline=deadline)
                if winner is None or not write_allowed(view.watermark, winner):
                    return HandleResult.YIELDED
                state = winner

        plan = plan_sends(messages, state)
        if plan.update_parent or view.watermark.newer_than(state.watermark):
            state = replace(state, parent_text=messages.parent.text, watermark=view.watermark)
            self._write_parent(state, deadline)

        assert state.parent_ref is not None
        for entry in plan.entries:
            self._transport.post_reply(channel, state.parent_ref, entry.text, broadcast=entry.broadcast, deadline=deadline)
            state = replace(state, sent_keys=state.sent_keys | {entry.key})
            self._store.save(state, deadline=deadline)
        for alert in plan.alerts:
            self._transport.post_reply(channel, state.parent_ref, alert.text, broadcast=False, deadline=deadline)
            state = replace(state, sent_keys=state.sent_keys | {alert.key})
            self._store.save(state, deadline=deadline)
        return HandleResult.SENT

    def _final_check(self, view: ProcessView, messages: MessageSet, deadline: float) -> None:
        """Spec 7.1 rule 3: read the result back once and repair it if a late writer slipped in."""
        self._sleep(self._settings.final_check_delay_s)
        latest = self._store.load(view.key, deadline=deadline)
        if latest is None or latest.parent_ref is None:
            return
        if latest.watermark is not None and latest.watermark.newer_than(view.watermark):
            return
        if latest.parent_text == messages.parent.text and latest.watermark == view.watermark:
            return
        log.warning("chappe: repaired a late overwrite of the final message", extra={"chappe_key": view.key})
        self._metrics("chappe.final_repaired")
        self._write_parent(replace(latest, parent_text=messages.parent.text, watermark=view.watermark), deadline)

    def _mark_degraded(self, view: ProcessView, sent: SentState | None, exc: TransportError, deadline: float) -> None:
        log.error("chappe: Slack refused (%s); stopping for this run", exc.code, extra={"chappe_key": view.key})
        if sent is None or sent.parent_ref is None:
            return
        try:
            self._store.save(replace(sent, degraded=True), deadline=deadline)
        except Exception:
            log.exception("chappe: could not record the degraded state")
```

```python
from __future__ import annotations

import logging
from collections.abc import Callable
from typing import Any

from airflow.sdk import BaseOperator

from chappe.integrations.airflow import callbacks
from chappe.integrations.airflow.marker import MARKER_ATTR, MilestoneSpec

log = logging.getLogger("chappe")

_CALLBACKS: tuple[tuple[str, Callable[..., None]], ...] = (
    ("on_execute_callback", callbacks.on_step_started),
    ("on_success_callback", callbacks.on_step_succeeded),
    ("on_failure_callback", callbacks.on_step_failed),
    ("on_skipped_callback", callbacks.on_step_skipped),
)


def _append_callback(op: BaseOperator, attr: str, callback: Callable[..., None]) -> None:
    if not hasattr(op, attr):
        return
    current = getattr(op, attr)
    if current is None:
        updated: list[Any] = [callback]
    elif isinstance(current, list):
        updated = current if callback in current else [*current, callback]
    else:
        updated = [current] if current is callback else [current, callback]
    setattr(op, attr, updated)


def mark_operator(op: BaseOperator, spec: MilestoneSpec) -> BaseOperator:
    setattr(op, MARKER_ATTR, spec)
    for attr, callback in _CALLBACKS:
        _append_callback(op, attr, callback)
    return op


class _MilestoneTask:
    """Wraps a TaskFlow task so each call marks the operator it creates."""

    def __init__(self, inner: Any, spec: MilestoneSpec) -> None:
        self._inner = inner
        self._spec = spec

    def __call__(self, *args: Any, **kwargs: Any) -> Any:
        result = self._inner(*args, **kwargs)
        op = getattr(result, "operator", None)
        if isinstance(op, BaseOperator):
            mark_operator(op, self._spec)
        else:
            log.warning("chappe: @milestone could not find the operator for %r; it will not be reported", self._inner)
        return result

    def expand(self, *args: Any, **kwargs: Any) -> Any:
        log.warning(
            "chappe: mapped tasks are not supported in 0.0.1; %r will not be reported",
            getattr(self._inner, "function", self._inner),
        )
        return self._inner.expand(*args, **kwargs)

    def __getattr__(self, name: str) -> Any:
        return getattr(self._inner, name)


def milestone(target: Any = None, title: str | None = None, *, section: str | None = None) -> Any:
    """Mark a task as a milestone.

    @milestone("Title") above @task, bare @milestone, or milestone(operator, "Title").
    """
    if isinstance(target, BaseOperator):
        return mark_operator(target, MilestoneSpec(title, section))
    if target is not None and not isinstance(target, str):
        return _MilestoneTask(target, MilestoneSpec(None, section))
    spec = MilestoneSpec(target, section)

    def decorate(task_decorator: Any) -> _MilestoneTask:
        return _MilestoneTask(task_decorator, spec)

    return decorate
```

```python
# src/chappe/integrations/airflow/structure.py
"""DAG → sections and steps (spec 4.1.1)."""

from __future__ import annotations

import heapq
from dataclasses import dataclass
from typing import Any

from chappe.config.models import MilestoneOverride, ProcessConfig
from chappe.integrations.airflow.marker import MilestoneSpec, milestone_spec


@dataclass(frozen=True, slots=True)
class SectionDef:
    key: str
    title: str


@dataclass(frozen=True, slots=True)
class StepDef:
    task_id: str
    title: str
    section_key: str


@dataclass(frozen=True, slots=True)
class ProcessStructure:
    sections: tuple[SectionDef, ...]
    steps: tuple[StepDef, ...]


def readable(identifier: str) -> str:
    words = [w for w in identifier.replace("-", "_").split("_") if w]
    text = " ".join(words)
    return text[:1].upper() + text[1:]


def _topological_order(dag: Any) -> list[str]:
    ids = list(dag.task_dict)
    index = {task_id: i for i, task_id in enumerate(ids)}
    indegree = {task_id: len(dag.task_dict[task_id].upstream_task_ids) for task_id in ids}
    ready = [(index[t], t) for t in ids if indegree[t] == 0]
    heapq.heapify(ready)
    order: list[str] = []
    while ready:
        _, task_id = heapq.heappop(ready)
        order.append(task_id)
        for downstream in dag.task_dict[task_id].downstream_task_ids:
            indegree[downstream] -= 1
            if indegree[downstream] == 0:
                heapq.heappush(ready, (index[downstream], downstream))
    return order


def _outermost_group(task: Any) -> Any | None:
    group = getattr(task, "task_group", None)
    if group is None or group.group_id is None:
        return None
    while group.parent_group is not None and group.parent_group.group_id is not None:
        group = group.parent_group
    return group


def _step_title(task: Any, spec: MilestoneSpec, override: MilestoneOverride | None) -> str:
    if override is not None and override.title:
        return override.title
    if spec.title:
        return spec.title
    display = getattr(task, "task_display_name", None)
    if display and display != task.task_id:
        return str(display)
    return readable(task.task_id.rsplit(".", 1)[-1])


def _section(
    task: Any, spec: MilestoneSpec, override: MilestoneOverride | None, default: SectionDef
) -> SectionDef:
    if spec.section:
        return SectionDef(spec.section, spec.section)
    if override is not None and override.section:
        return SectionDef(override.section, override.section)
    group = _outermost_group(task)
    if group is not None:
        display = getattr(group, "group_display_name", None)
        title = display if display and display != group.group_id else readable(group.group_id)
        return SectionDef(group.group_id, str(title))
    return default


def build_structure(dag: Any, process: ProcessConfig) -> ProcessStructure:
    ref = next((d for d in process.dags if d.dag_id == dag.dag_id), None)
    default = SectionDef(dag.dag_id, ref.section if ref and ref.section else readable(dag.dag_id))
    found: list[StepDef] = []
    titles: dict[str, str] = {}
    for task_id in _topological_order(dag):
        task = dag.get_task(task_id)
        spec = milestone_spec(task)
        if spec is None:
            continue
        override = process.milestones.get(task_id)
        if override is not None and override.hidden:
            continue
        section = _section(task, spec, override, default)
        titles.setdefault(section.key, section.title)
        found.append(StepDef(task_id, _step_title(task, spec, override), section.key))

    order: list[str] = []
    for step in found:
        if step.section_key not in order:
            order.append(step.section_key)
    sections = tuple(
        SectionDef(key, process.sections[key].title if key in process.sections else titles[key]) for key in order
    )
    steps = tuple(step for key in order for step in found if step.section_key == key)
    return ProcessStructure(sections, steps)
```

```python
from dataclasses import dataclass
from datetime import datetime
from typing import Any, Protocol
from urllib.parse import quote

import httpx


@dataclass(frozen=True, slots=True)
class TaskRecord:
    state: str | None
    started_at: datetime | None
    ended_at: datetime | None


class TaskStateReader(Protocol):
    def read(self, dag_id: str, run_id: str) -> Mapping[str, TaskRecord]: ...


def _parse(value: Any) -> datetime | None:
    if not value:
        return None
    return datetime.fromisoformat(str(value).replace("Z", "+00:00"))


class RestTaskStateReader:
    def __init__(
        self, base_url: str, username: str, password: str, *, timeout: float = 5.0, client: httpx.Client | None = None
    ) -> None:
        self._base = base_url.rstrip("/")
        self._credentials = {"username": username, "password": password}
        self._client = client or httpx.Client(timeout=timeout)
        self._token: str | None = None

    def _headers(self) -> dict[str, str]:
        if self._token is None:
            response = self._client.post(f"{self._base}/auth/token", json=self._credentials)
            response.raise_for_status()
            self._token = str(response.json()["access_token"])
        return {"Authorization": f"Bearer {self._token}"}

    def read(self, dag_id: str, run_id: str) -> Mapping[str, TaskRecord]:
        url = f"{self._base}/api/v2/dags/{quote(dag_id, safe='')}/dagRuns/{quote(run_id, safe='')}/taskInstances"
        response = self._client.get(url, params={"limit": 1000}, headers=self._headers())
        if response.status_code == 401:
            self._token = None
            response = self._client.get(url, params={"limit": 1000}, headers=self._headers())
        response.raise_for_status()
        records: dict[str, TaskRecord] = {}
        for item in response.json().get("task_instances", []):
            if item.get("map_index", -1) not in (-1, None):
                continue
            records[str(item["task_id"])] = TaskRecord(item.get("state"), _parse(item.get("start_date")), _parse(item.get("end_date")))
        return records
```

```python
STATE_MAP: dict[str, StepState] = {
    "none": StepState.PENDING,
    "scheduled": StepState.PENDING,
    "queued": StepState.PENDING,
    "restarting": StepState.PENDING,
    "running": StepState.RUNNING,

    "deferred": StepState.RUNNING,
    "success": StepState.SUCCEEDED,
    "failed": StepState.FAILED,
    "upstream_failed": StepState.FAILED,
    "skipped": StepState.SKIPPED,
    "removed": StepState.SKIPPED,
}
_AIRFLOW_NAME = {
    StepState.RUNNING: "running",
    StepState.SUCCEEDED: "success",
    StepState.FAILED: "failed",
    StepState.SKIPPED: "skipped",
    StepState.PENDING: "queued",
}
_TEMPLATES = SandboxedEnvironment(undefined=StrictUndefined, autoescape=False)


def map_state(airflow_state: str | None) -> StepState:
    return STATE_MAP.get(str(airflow_state), StepState.PENDING) if airflow_state else StepState.PENDING


def render_title(template: str, *, params: Mapping[str, Any], dag_id: str, run_id: str) -> str:
    try:
        text = _TEMPLATES.from_string(template).render(params=params, dag_id=dag_id, run_id=run_id).strip()
    except Exception:
        text = ""
    return text or f"{dag_id} · {run_id}"


def _overlay(record: TaskRecord | None, event: ChappeEvent) -> TaskRecord:
    assert event.step_state is not None
    started = record.started_at if record else None
    if event.kind is EventKind.STEP_STARTED or started is None:
        started = started or event.occurred_at
    ended = event.occurred_at if event.step_state.finished else None
    return TaskRecord(_AIRFLOW_NAME[event.step_state], started, ended)


class AirflowSource:
    def __init__(
        self,
        process: ProcessConfig,
        reader: TaskStateReader,
        *,
        ui_base_url: str,
        now: Callable[[], datetime],
    ) -> None:
        self._process = process
        self._reader = reader
        self._ui = ui_base_url.rstrip("/")
        self._now = now

    def _run_url(self, event: ChappeEvent) -> str:
        return f"{self._ui}/dags/{quote(event.dag_id, safe='')}/runs/{quote(event.run_id, safe='')}"

    def snapshot(self, event: ChappeEvent) -> ProcessView | None:
        structure = build_structure(event.payload["dag"], self._process)
        if not structure.steps:
            return None
        records = dict(self._reader.read(event.dag_id, event.run_id))
        if event.step_key is not None and event.step_state is not None:
            records[event.step_key] = _overlay(records.get(event.step_key), event)

        run_url = self._run_url(event)
        steps: dict[str, list[StepView]] = {}
        for step in structure.steps:
            record = records.get(step.task_id)
            state = map_state(record.state if record else None)
            error = event.error if step.task_id == event.step_key else None
            if record is not None and record.state == "upstream_failed":
                error = error or "An upstream task failed"
            steps.setdefault(step.section_key, []).append(
                StepView(
                    key=step.task_id,
                    title=step.title,
                    state=state,
                    started_at=record.started_at if record else None,
                    ended_at=record.ended_at if record else None,
                    error=error,
                    links=(Link("Log", f"{run_url}/tasks/{quote(step.task_id, safe='.')}"),),
                )
            )
        sections = tuple(SectionView(s.key, s.title, tuple(steps.get(s.key, ()))) for s in structure.sections)

        all_steps = [s for section in sections for s in section.steps]
        if event.kind is EventKind.RUN_FINISHED and event.process_state is not None:
            state = event.process_state
        elif any(s.state is not StepState.PENDING for s in all_steps):
            state = ProcessState.RUNNING
        else:
            state = ProcessState.PENDING

        dag_run = event.payload.get("dag_run")
        started = getattr(dag_run, "start_date", None) or min(
            (s.started_at for s in all_steps if s.started_at is not None), default=None
        )
        params = event.payload.get("params") or {}
        return ProcessView(
            key=process_key(event.dag_id, event.run_id),
            title=render_title(self._process.title, params={k: params[k] for k in params}, dag_id=event.dag_id, run_id=event.run_id),
            state=state,
            started_at=started,
            ended_at=event.occurred_at if state.finished else None,
            now=self._now(),
            sections=sections,
            links=(Link("Airflow run", run_url),),
        )
```

```python
def base_url(info: ConnectionInfo) -> str:
    host = (info.host or "").rstrip("/")
    if not host.startswith(("http://", "https://")):
        host = f"http://{host}"
    if info.port and not host.rsplit("/", 1)[-1].count(":"):
        host = f"{host}:{info.port}"
    return host
```

```python
"""Loads config once per process and builds one engine per Chappe process."""

from __future__ import annotations

import logging
from collections.abc import Callable
from datetime import datetime, timezone
from zoneinfo import ZoneInfo

from chappe.config.components import validate_components
from chappe.config.loader import chappe_enabled, load_settings

from chappe.core.errors import ChappeConfigError

from chappe.integrations.airflow.connections import ConnectionInfo, airflow_connection, base_url

from chappe.integrations.airflow.source import AirflowSource
from chappe.registry import load_component
from chappe.stores.slack_metadata import SlackMetadataStore
from chappe.themes.builtin.plain import PlainTheme
from chappe.themes.tokens import resolve_tokens
from chappe.transports.slack.api import WebClientSlackApi
from chappe.transports.slack.transport import SlackTransport

log = logging.getLogger("chappe")


def _metrics(name: str) -> None:
    try:
        from airflow.stats import Stats

        Stats.incr(name)
    except Exception:
        return


class Runtime:
    def __init__(
        self, settings: ChappeSettings, connections: Callable[[str], ConnectionInfo] = airflow_connection
    ) -> None:
        self.settings = settings
        self._connections = connections
        self._engines: dict[str, Engine] = {}

    def resolve(self, process: str | None, dag_id: str) -> tuple[str, ProcessConfig] | None:
        if process is not None:
            config = self.settings.processes.get(process)
            return (process, config) if config is not None else None
        return self.settings.process_for_dag(dag_id)

    def engine(self, name: str) -> Engine:
        if name not in self._engines:
            self._engines[name] = self._build(name)
        return self._engines[name]

    def _build(self, name: str) -> Engine:
        settings, process = self.settings, self.settings.processes[name]
        defaults = settings.defaults
        theme_config = settings.theme_for(process)
        theme = load_component("theme", theme_config.name)()
        api = WebClientSlackApi(self._connections(defaults.transport.connection_id).password or "")
        transport = SlackTransport(api)
        store = SlackMetadataStore(api, process.channel, scan_depth=defaults.store.scan_depth)
        api_info = self._connections(defaults.airflow_api.connection_id)
        api_base = base_url(api_info)
        reader = RestTaskStateReader(api_base, api_info.login or "", api_info.password or "")
        source = AirflowSource(
            process, reader, ui_base_url=defaults.airflow_api.ui_base_url or api_base, now=lambda: datetime.now(timezone.utc)
        )
        context = RenderContext(
            tokens=resolve_tokens(theme_config.name, theme_config.tokens),
            fmt=transport.formatter,
            tz=ZoneInfo(defaults.time.timezone),
            alert_mention=process.alerts.mention,
        )
        return Engine(
            source=source,
            theme=theme,
            fallback_theme=PlainTheme(),
            context=context,
            transport=transport,
            store=store,
            settings=EngineSettings(
                channel=process.channel,
                event_budget_s=defaults.budgets.event_seconds,
                final_budget_s=defaults.budgets.final_seconds,
                final_check_delay_s=defaults.budgets.final_check_delay_seconds,
            ),
            enabled=lambda: chappe_enabled(settings) and process.enabled,
            metrics=_metrics,
        )


_runtime: Runtime | None = None
_loaded = False


def set_runtime(runtime: Runtime | None) -> None:
    global _runtime, _loaded
    _runtime, _loaded = runtime, runtime is not None


def get_runtime() -> Runtime | None:
    global _runtime, _loaded
    if _loaded:
        return _runtime
    _loaded = True
    try:
        settings = load_settings()
        validate_components(settings)
        _runtime = Runtime(settings)
    except ChappeConfigError as exc:
        log.error("chappe is disabled: %s", exc)
        _runtime = None
    return _runtime
```

```python
"""Task callbacks attached by @milestone, and the run-finished dispatch used by ChappeNotifier."""

from __future__ import annotations

import logging
from collections.abc import Mapping
from datetime import datetime, timezone
from typing import Any

from chappe.core.events import ChappeEvent, EventKind
from chappe.core.model import ProcessState, StepState

log = logging.getLogger("chappe")


def _error_text(context: Mapping[str, Any]) -> str | None:
    exc = context.get("exception")
    return f"{type(exc).__name__}: {exc}"[:300] if exc else None


def _dispatch(
    context: Mapping[str, Any],
    kind: EventKind,
    *,
    step_state: StepState | None = None,
    process_state: ProcessState | None = None,
    process: str | None = None,
) -> None:
    try:
        from chappe.integrations.airflow.runtime import get_runtime

        runtime = get_runtime()
        if runtime is None:
            return
        dag, dag_run = context["dag"], context["dag_run"]
        found = runtime.resolve(process, dag.dag_id)
        if found is None:
            return
        name, _ = found
        ti = context.get("ti")
        event = ChappeEvent(
            kind=kind,
            process=name,
            dag_id=dag.dag_id,
            run_id=dag_run.run_id,
            occurred_at=datetime.now(timezone.utc),
            step_key=ti.task_id if ti is not None and kind is not EventKind.RUN_FINISHED else None,
            step_state=step_state,
            process_state=process_state,
            error=_error_text(context),
            payload=context,
        )
        runtime.engine(name).handle(event)
    except Exception:
        log.exception("chappe: callback failed; the pipeline is not affected")


def on_step_started(context: Mapping[str, Any]) -> None:
    _dispatch(context, EventKind.STEP_STARTED, step_state=StepState.RUNNING)


def on_step_succeeded(context: Mapping[str, Any]) -> None:
    _dispatch(context, EventKind.STEP_FINISHED, step_state=StepState.SUCCEEDED)


def on_step_failed(context: Mapping[str, Any]) -> None:
    _dispatch(context, EventKind.STEP_FINISHED, step_state=StepState.FAILED)


def on_step_skipped(context: Mapping[str, Any]) -> None:
    _dispatch(context, EventKind.STEP_FINISHED, step_state=StepState.SKIPPED)


def dispatch_run_finished(context: Mapping[str, Any], process: str | None, state: ProcessState) -> None:
    _dispatch(context, EventKind.RUN_FINISHED, process_state=state, process=process)
```

```python
from airflow.sdk import BaseNotifier  # path confirmed in the spike (ADR-0004)

def _run_state(context: Mapping[str, Any]) -> ProcessState:
    state = getattr(context.get("dag_run"), "state", None)
    value = getattr(state, "value", state)
    if value == "failed" or context.get("exception"):
        return ProcessState.FAILED
    return ProcessState.SUCCEEDED


class ChappeNotifier(BaseNotifier):  # type: ignore[misc]

    def __init__(self, process: str | None = None) -> None:
        super().__init__()
        self.process = process

    def notify(self, context: Mapping[str, Any]) -> None:
        dispatch_run_finished(context, self.process, _run_state(context))
```
